how to sign a request

    
METHOD \n PATH \n TIMESTAMP \n NONCE \n SHA256(BODY)

headers:
  X-Api-Key:       pbk_...
  X-Api-Timestamp: 1765432100        (unix seconds)
  X-Api-Nonce:     any-unique-string
  X-Api-Signature: hex(HMAC-SHA256(secret, string above))

endpoints:
  GET    /api/v1/codes                  list your codes        codes:read
  GET    /api/v1/codes/{credential_id}  one code               codes:read
  POST   /api/v1/codes                  create                 codes:write
  PATCH  /api/v1/shares/{share_id}      label, expiry, cap     codes:write
  DELETE /api/v1/shares/{share_id}      switch one copy off    codes:write
  DELETE /api/v1/codes/{credential_id}  delete outright        codes:write

POST /api/v1/codes body:
  { "photo_b64": "...", "ciphertext_b64": "...", "nonce_b64": "...",
    "label": "partner app", "fragment_key": "...", "coverage": "full" }

We never accept a plaintext payload. Encrypt on your side; send ciphertext.
