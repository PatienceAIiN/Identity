This isn't a QR generator.

Making a code that looks like a picture is the easy half, and it isn't ours. The difference is what the code is, and what you can still do about it after you've handed it out.

An ordinary QR code Identity
What it carries Your actual data, written in the open. Anyone who scans it has it, and anyone who photographs it keeps it. A meaningless id. What it opens is locked on your device first, and the key rides in the part of a link that browsers never send to a server.
After you share it It works forever. A printed code is a decision you can't take back. Switch any copy off whenever you like. The next person to scan is told it's off, and told nothing else.
If it leaks One code for everyone, so there's nothing to trace. You can't tell where it got out. Every copy you share is its own code with its own scan history, so a leak points at the copy it came from.
If the picture is edited Nothing to check against. A swapped face still scans the same. Check a picture later and we tell you whether it's the same one the code was made for, a harmless re-save, or changed — and where.
Does it still look like you No. It's a grid of squares, or a picture with a code sitting on top of it. The picture is the code, across the whole image. A face is given extra room, and we show you a measured score rather than asking you to squint.
Before you're shown it Nothing is checked. You find out it won't scan when someone tries. Every code is scanned by real decoders — flat, re-compressed, tilted and shrunk — before it reaches you, and you're shown the number.
Reader needed Any phone camera. Any standard scanner — no app of ours required. Verified against two independent open-source decoders; testing on phone cameras is still in progress and we'll say so until it's done.
